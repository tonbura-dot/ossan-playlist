# おっさんのプレイリスト

AIですることがなくなったおっさんの窓際。
室蘭で見つけた小さな面白いものを、写真と一言で残すサイトです（Astro 製の静的サイト）。

## 記事の書き方

1. `src/content/posts/` の中に、記事ごとのフォルダを作る（フォルダ名がそのまま URL になる。英数字とハイフンがおすすめ）
2. フォルダの中に `index.md` と写真を置く

```
src/content/posts/
  oshiruko-jihanki/
    index.md
    photo.jpg
    can.jpg
```

`index.md` の書き方:

```markdown
---
title: 自販機のおしるこが、もう帰ってきていた
date: 2026-09-28
category: 発見
image: ./photo.jpg
description: まだ半袖の人がいるのに、左上の定位置におしるこ。
---

本文はふつうに書く。

![写真の説明](./can.jpg)

**一言感想:** 太字にすると、蛍光ペンを引いたような見た目になる。
```

| 項目 | 必須 | 内容 |
| --- | --- | --- |
| title | ○ | タイトル |
| date | ○ | 投稿日（`2026-10-11` の形） |
| category | ○ | `発見` / `レビュー` / `日常`（ほかの名前も使える） |
| image | | トップ画像。同じフォルダの写真を `./ファイル名` で指定 |
| description | | 一覧に出る短い説明（一言感想） |

写真は自動で軽い形式（WebP）に変換され、スマホ向けの小さいサイズも作られます。

## 設定を変える

サイト名・キャッチ・プロフィールの要約・カテゴリーは `src/site.config.ts` にまとまっています。

- **お問い合わせフォーム**: [Formspree](https://formspree.io) に無料登録してフォームを作り、発行された ID を `formspreeId` に入れる。空のままだとフォームは「準備中」と表示される。スパム対策として、人には見えない入力欄（ハニーポット）を入れてある。Formspree の管理画面で reCAPTCHA もオンにできる。
- **ランダムに1本読む**: 記事が `randomButtonMinPosts`（今は5本）以上になると、トップページに自動で出る。

## オープニング演出

宇宙 → 地球 → 日本 → 北海道 → 室蘭 → 白鳥大橋 → 雪でホワイトアウト → 記事一覧 → トップページ（約14秒）。

- 初回だけ再生する（ブラウザの localStorage に記録。記録できない環境では毎回再生）
- 右上の「スキップ」ボタン、または Esc キーで飛ばせる
- OS の「視差効果を減らす」がオンなら、拡大や移動をせず、場面の切り替えだけで見せる
- フッターの「オープニングをもう一度見る」（`/?opening=1`）でいつでも再生できる
- 地図は主な岬や町の位置を手で拾った、簡略化した SVG（本物の地図データは使っていない）
- 演出のプログラムが読み込めなかったときは、5秒で通常のページに戻る

確認用の URL（場面を指定して止められる）:

- `/?opening=1&ot=9&ofreeze` … 9秒目（白鳥大橋）で止める
- `/?opening=1&oreduce` … 「視差効果を減らす」版で再生

演出の中身: `src/components/opening/`（`geo.ts` が地図の座標、`opening.ts` が動き、`Opening.astro` が見た目と白鳥大橋の絵）

## 下書き

記事の先頭に `draft: true` と書くと下書きになり、公開中のサイトには出ません（`npm run dev` では見えます）。仕上がったらその行を消します。

## ネタ帳（スマホ用メモアプリ）

`/neta/`（公開後は `https://tonbura-dot.github.io/ossan-playlist/neta/`）。サイトのメニューには出していない、自分用のページです。

- 見つけたものを、写真（最大6枚、自動で縮小）と一言でメモできる
- 「記事の材料にする」で、写真ごと共有（依頼文付き）、依頼文のコピー、記事の下書き（`draft: true` 付き Markdown）の書き出しができる
- 「まだ／記事にした／すべて」で絞り込める
- データはそのスマホのブラウザの中だけに保存（サーバーには送らない）。ときどき「バックアップを保存」しておくと安心
- iPhone では Safari の共有ボタン →「ホーム画面に追加」でアプリのように使える。ホーム画面から開いたものと Safari で開いたものは中身が別々になるので、どちらかに決めて使う
- 電波がなくても、一度開いたことがあれば使える

中身: `src/pages/neta/index.astro`（画面）、`src/neta/`（保存・書き出しの処理）、`public/neta/`（アイコン、ホーム画面用の設定、オフライン用の仕組み）

## 手元で動かす

Node.js 22 以上が必要です。

```bash
npm install
npm run dev      # http://localhost:4321 で確認しながら書く
npm test         # 本番用に組み立てて、リンク切れなどを自動チェック
```

`npm test` は次を確認します: 必要なページがそろっているか、記事が3本以上あるか、全ページのタイトル・説明・スマホ用設定・見出し、サイト内のリンクと画像がすべて実在するか、オープニングの部品がトップにだけ入っているか。

## 公開（GitHub Pages）

1. GitHub で新しいリポジトリを作り（例: `ossan-playlist`）、このフォルダを push する
2. リポジトリの **Settings → Pages → Build and deployment → Source** を「**GitHub Actions**」にする
3. 以後、`main` ブランチに push するたびに自動でチェック → 公開される（チェックに失敗したら公開されない）

公開先の URL は `https://<GitHubのユーザー名>.github.io/ossan-playlist/` になります。
サイトの住所（`SITE` と `BASE_PATH`）は GitHub Actions が自動で渡すので、設定は不要です。
