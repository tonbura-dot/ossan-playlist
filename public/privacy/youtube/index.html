hint-bar-uploader プライバシーポリシー

最終更新日: 2026年11月10日

hint-bar-uploader（以下「本ツール」）は、YouTube チャンネル「ヒント屋のヒント。」の運営者が、自分で制作した動画を自分のチャンネルにアップロードするためだけに使う個人用ツールです。一般には公開・配布していません。

本ツールが使う YouTube API サービス

本ツールは YouTube API サービスを利用しています。本ツールを使うことで、YouTube 利用規約に同意したものとみなされます。Google によるデータの扱いは Google プライバシーポリシーをご覧ください。

アクセスする情報と使い方

  • 運営者本人の YouTube チャンネル情報（チャンネル名・ID・登録者数・動画数）: 正しいチャンネルにつながっているかの確認だけに使います。
  • 動画のアップロード、タイトル・説明文・タグ・公開設定・サムネイルの設定: 運営者本人の動画に対してだけ行います。

本ツールは、運営者以外のユーザーの情報を集めません。取得した情報を第三者に販売・共有・提供することはありません。広告や分析のためにも使いません。

保存

認証トークンは、運営者本人のパソコンと、運営者が管理する作業環境の中にだけ保存します。アップロードした動画の ID とタイトルの記録は、運営者の作業フォルダにだけ残します。Cookie は使いません。

アクセスの取り消し

本ツールへのアクセス許可は、Google アカウントのセキュリティ設定からいつでも取り消せます。取り消すと、保存していたトークンは使えなくなります。

GitHub の Issues からご連絡ください。

hint-bar-uploader Privacy Policy

Last updated: November 10, 2026

hint-bar-uploader ("the Tool") is a private, single-user tool. Its only purpose is to let the owner of the YouTube channel "ヒント屋のヒント。" upload videos they produced themselves to their own channel. It is not offered or distributed to the public.

Use of YouTube API Services

The Tool uses YouTube API Services. By using the Tool you agree to be bound by the YouTube Terms of Service. See the Google Privacy Policy for how Google handles data.

Information accessed and how it is used

  • The owner's own channel information (title, ID, subscriber and video counts), used only to confirm the Tool is connected to the correct channel.
  • Uploading videos and setting title, description, tags, privacy status and thumbnail, only for the owner's own videos.

The Tool does not collect information about anyone other than the owner. No data is sold, shared or disclosed to third parties, and none is used for advertising or analytics.

Storage

OAuth tokens are stored only on the owner's computer and in a work environment the owner controls. A log of uploaded video IDs and titles is kept only in the owner's working folder. The Tool does not use cookies.

Revoking access

Access can be revoked at any time via Google security settings. Revoking access makes any stored token unusable.

Contact

Please contact us via GitHub Issues.
